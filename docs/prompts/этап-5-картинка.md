---

Ты работаешь в репозитории taec432-maker/gonki-na-vyzhivanie (ветка main). Заказчик — Александр, не программист, общение по-русски.

Сначала прочитай целиком ТЗ.md, CHANGELOG.md, docs/РЕШЕНИЯ.md (если есть) и этот промпт. Правила раздела 11 ТЗ обязательны: без заглушек, `npm run check` зелёный перед пушем, детерминизм по seed, бюджет 16 мс на кадр, свободные лицензии с записью в ASSETS.md, маленькие коммиты по-русски, пуш в main.

Если в ТЗ чего-то нет — выбери разумный вариант, запиши в docs/РЕШЕНИЯ.md и продолжай, не останавливайся с вопросами. Вопросы к заказчику — в конец отчёта.

В конце: обнови CHANGELOG.md (что сделано / что не вошло / «Как проверить» — по шагам для заказчика), положи 3–5 скриншотов в docs/screenshots/этап-5/, запушь и напиши заказчику короткий отчёт по-русски в том же формате.

Задача этапа 5 — картинка (раздел 2 и «Этап 5» ТЗ). Цель — реализм уровня Slow Roads / HexGL при 60 fps на Mac mini (Apple Silicon) в OBS с 12 машинами.

1. Настоящие glTF-машины: минимум 8 реалистичных из ростера раздела 8 (включая 2–3 необычных), только свободные лицензии (Sketchfab CC0/CC-BY, Poly Haven, Quaternius), запись каждой в ASSETS.md, приведение к единому масштабу и осям, колёса wheel_FL/FR/RL/RR, Draco/Meshopt. Никаких реальных марок и логотипов.
2. Освещение: HDRI по локации, солнце с каскадными тенями (CSM), туман; пост: bloom, GTAO/SSAO, лёгкий motion blur, ACES, color grading под локацию.
3. Частицы: дым и искры при таране, пыль из-под колёс по типу поверхности, выхлоп, нитро-пламя, огонь и взрыв, дождь (для ночного города — подготовить систему, сама трасса — этап 6), следы шин (decal-полосы).
4. Дрожание камеры на ударах, повреждённые материалы, мокрый асфальт (отражения).
5. Переключатель качества Высокое / Среднее / Эфир (разрешение, тени, пост, частицы) с сохранением.
6. Оптимизация: инстансинг, LOD, ≤ 300 draw calls, текстуры ≤ 2K, профиль кадра (renderer.info + performance) в Playwright-отчёт и в CHANGELOG. dist/ ≤ 150 МБ; бинарники > 5 МБ — Git LFS или CDN с кэшем.

Готово, когда: скриншоты не стыдно поставить рядом с Slow Roads; заказчик подтверждает 60 fps в OBS; профиль кадра в CHANGELOG.
