# Промпт для Opus 5.5 — Этап 1: Гонка

Скопируй всё, что ниже линии, в новую облачную сессию с репозиторием `taec432-maker/gonki-na-vyzhivanie`.

---

Ты работаешь в репозитории taec432-maker/gonki-na-vyzhivanie (ветка main). Заказчик — Александр, не программист, общение по-русски.

Сначала прочитай целиком ТЗ.md, CHANGELOG.md, docs/РЕШЕНИЯ.md (если есть) и этот промпт. Правила раздела 11 ТЗ обязательны: без заглушек, `npm run check` зелёный перед пушем, детерминизм по seed, бюджет 16 мс на кадр, свободные лицензии с записью в ASSETS.md, маленькие коммиты по-русски, пуш в main.

Если в ТЗ чего-то нет — выбери разумный вариант, запиши в docs/РЕШЕНИЯ.md и продолжай, не останавливайся с вопросами. Вопросы к заказчику — в конец отчёта.

В конце: обнови CHANGELOG.md (что сделано / что не вошло / «Как проверить» — по шагам для заказчика), положи 3–5 скриншотов в docs/screenshots/этап-1/, запушь и напиши заказчику короткий отчёт по-русски в том же формате.

Задача этапа 1 — гонка (раздел 10 ТЗ, «Этап 1»).

1. Полноценный raycast-vehicle: подвеска, сцепление по типу поверхности, занос, параметры из JSON машины (раздел 8). Пока одна-две процедурные машины с PBR-материалами (placeholder: true).
2. ИИ-пилоты (src/ai): racing line по сплайну с индивидуальным боковым смещением, обгон (смена линии, когда впереди медленнее), уклонение от препятствий, «характер» (агрессивный/осторожный/ровный), возврат на трассу после вылета, анти-застревание (если 3 с нет прогресса — мягкий респаун на последнем чекпойнте).
3. Трасса «Порт / промзона» (раздел 9) — первая настоящая: сплайн с рельефом, ширина, чекпойнты, стартовая решётка на 12 мест, инстансированные пропсы (контейнеры, краны, бочки — пока простые меши), пресет света «день».
4. src/race: круги, чекпойнты (нельзя срезать), позиции по кругу + прогрессу вдоль сплайна, финиш, таблица результатов, лимит времени. Unit-тесты на чекпойнты/круги/позиции.
5. Камера-режиссёр: за лидером с плавными переключениями, обзорная при старте, ручной выбор машины из /control.
6. HUD: позиции слева, круг/время, мини-таблица.
7. Soak-тест Playwright: 10 заездов по 8 ботов подряд, ни одного застревания, финиш у всех.

Готово, когда: 8 ботов честно проезжают 3 круга, позиции и финиш считаются правильно, 10 заездов подряд без застреваний.
