# Промпт для Opus 5.5 — Этап 2: Зрители

Скопируй всё, что ниже линии, в новую облачную сессию с репозиторием `taec432-maker/gonki-na-vyzhivanie`.

---

Ты работаешь в репозитории taec432-maker/gonki-na-vyzhivanie (ветка main). Заказчик — Александр, не программист, общение по-русски.

Сначала прочитай целиком ТЗ.md, CHANGELOG.md, docs/РЕШЕНИЯ.md (если есть) и этот промпт. Правила раздела 11 ТЗ обязательны: без заглушек, `npm run check` зелёный перед пушем, детерминизм по seed, бюджет 16 мс на кадр, свободные лицензии с записью в ASSETS.md, маленькие коммиты по-русски, пуш в main.

Если в ТЗ чего-то нет — выбери разумный вариант, запиши в docs/РЕШЕНИЯ.md и продолжай, не останавливайся с вопросами. Вопросы к заказчику — в конец отчёта.

В конце: обнови CHANGELOG.md (что сделано / что не вошло / «Как проверить» — по шагам для заказчика), положи 3–5 скриншотов в docs/screenshots/этап-2/, запушь и напиши заказчику короткий отчёт по-русски в том же формате.

Задача этапа 2 — зрители (раздел 10 ТЗ, «Этап 2»).

1. src/race: жизненный цикл lobby (45 с) → countdown (3 с) → race → podium (15 с) → lobby, по кругу, без участия стримера; ручные старт/стоп/рестарт из /control.
2. Игроки: заявка по userId (ник — username, обрезка 16 символов, фильтр для подписи), один игрок — одна машина, очередь при нехватке мест, боты-заполнители «Бот Рыжий/Серый/…» при < 6 зрителях, настройка 6–16 машин и числа кругов.
3. Ники над машинами: всегда читаемые (обводка, фон-плашка, масштаб по дистанции, не пересекаются с HUD), цвет ника = цвет машины.
4. Экран лобби: список записавшихся, очередь, обратный отсчёт, подсказка «напиши в чат, чтобы участвовать»; подиум с топ-3.
5. Mock-режим в /control: «+1 тест-игрок», «+20 случайных игроков», «удалить игрока» — через тот же путь, что и реальные события чата (src/bridge/mock.ts).
6. Скриншот 1080p с 12 никами — проверить читаемость в Playwright (скриншот + визуальная проверка размеров текста).

Готово, когда: в /control нажали «+20 игроков» — 12 поехали, 8 в очереди, после заезда очередь зашла; имена читаются на скриншоте 1080p.
