# Промпты по этапам

Один этап = одна облачная сессия Opus 5.5 с репозиторием `taec432-maker/gonki-na-vyzhivanie`.

Порядок: открыть файл этапа → скопировать текст под линией → вставить в новую сессию → дождаться отчёта → дважды щёлкнуть «Обновить и запустить.command» на Маке → посмотреть → написать правки (их можно давать в той же сессии или новой: «Прочитай ТЗ.md и CHANGELOG.md, затем исправь: …»).

| Этап | Файл | Что получится |
|---|---|---|
| 0 | этап-0-каркас.md | проект собирается, одна машина едет, скрипт и Pages работают |
| 1 | этап-1-гонка.md | 8 ботов гоняются по трассе «Порт», позиции и финиш |
| 2 | этап-2-зрители.md | лобби, ники, очередь, заезды по кругу |
| 3 | этап-3-tiktok-bridge-и-подарки.md | подключение к Bridge, подарки дают эффекты, лайки |
| 4 | этап-4-выживание-и-оружие.md | HP, таран, взрывы, всё оружие и пакости |
| 5 | этап-5-картинка.md | реалистичные машины, свет, эффекты, 60 fps |
| 6 | этап-6-трассы-и-машины.md | все 5 локаций, 16 машин, выбор машины |
| 7 | этап-7-эфир.md | звук, оверлей, стресс-тест, инструкция для стрима |

Этапы 0–2 можно давать подряд одной сессии, если первая прошла гладко: «Выполни этапы 0, 1 и 2 из docs/prompts по очереди, после каждого — коммит и запись в CHANGELOG».
