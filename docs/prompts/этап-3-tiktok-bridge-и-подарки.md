Задача этапа 3 — TikTok Bridge и подарки (разделы 5, 7 и «Этап 3» ТЗ).

1. src/bridge: клиент по разделу 5 ТЗ дословно: URL ws://127.0.0.1:3100/events?role=game&client=race (хост/порт в панели, резерв 3101), проверка welcome (bridge === "tiktok-bridge", protocolVersion === 1), игнор catchup, hello {role:"game",client:"race"}, события gift/chat/like, правило комбо (эффект один раз на repeatEnd/streaking=false, количество repeatCount, стоимость diamondCount×repeatCount), дедуп по eventId, test:true → метка «ТЕСТ», реконнект 1→30 с, статус в углу игры и в панели.
2. Фейковый Bridge для тестов: Vitest-сервер на `ws`, отдающий welcome + все три типа событий, включая серию комбо и дубликаты.
3. src/gifts: маппинг по тирам из раздела 7 (JSON) + переопределения по giftName/giftId; список подарков с ценами и иконками из GET http://127.0.0.1:3100/api/tiktok/gifts?withIcons=1 (с фолбэком, если Bridge недоступен); UI таблицы в /control; хранение в localStorage, импорт/экспорт JSON.
4. Эффекты первой очереди (src/combat): Нитро, Ракета (самонаводящаяся, пока без урона HP — урон появится на этапе 4, сейчас — толчок и визуал), Ремонт (пока без HP — заготовить интерфейс), Щит, Масло. Очередь эффектов, стак по времени.
5. Лента событий «Ник ▸ Подарок ▸ Эффект» с иконкой подарка, подсветка машины, звук-заглушка (короткий синтезированный, настоящие звуки — этап 7).
6. Лайки → общий нитро-бар (500, настройка) → всем нитро 3 с.
7. В /control: «подарить от игрока X подарок за N алмазов», «лайки ×50» — через тот же код, что и реальные события.

Готово, когда: с мок-кнопок панели Bridge (http://127.0.0.1:3100) подарок зрителя A даёт эффект машине A, комбо начисляется один раз, после перезапуска Bridge игра сама переподключается; тест с фейковым Bridge покрывает все три типа событий.
